GDrive JSON Secrets Generator

Convert GDrive links → JSON format for GDRIVE_LINKS secret

Compressed videos will be uploaded to this folder on GDrive
Paste full Google Drive shareable links

    

  


  

    How to use:

    1. Set folder name (e.g. "My Videos")

    2. Paste your GDrive shareable links (one per field)

    3. Click Generate JSON → copy the output

    4. Add as GDRIVE_LINKS in GitHub → Settings → Secrets and variables → Actions


    Example output:
    {"My Videos":["https://drive.google.com/file/d/1abc123/view","https://drive.google.com/file/d/2def456/view"]}
